# Комрадики
Консольная игра на Python, в которой вы играете за Кроша и его друзей, борющегося с капиталистами, пытающимися захватить Ромашковую долину.

## Особенности
- Нелинейный сюжет с 5+ концовками
- Пошаговая боевая система с разными врагами
- Возможность собирать команду друзей
- ASCII-графика локаций
- Система морального выбора (публичные/скрытые очки репутации)

##Управление
- [Enter] — продолжить, подтвердить выбор
- [Пробел] — пропустить анимацию текста

##Боевая система
Бои пошаговые. В свой ход выберите действие:
- Атака — нанести случайный урон (ваша атака ±5) выбранному врагу.
- Лечение — восстановить 35 HP (доступно только при наличии конфет).
- Взлом — мгновенно уничтожить робота, решив 3 арифметических примера (требует Пи́на в команде).
