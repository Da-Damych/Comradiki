# Комрадики
Консольная игра, в которой вы играете за Кроша, борющегося с капиталистами, захватившими Ромашковую долину.

## Особенности
- Нелинейный сюжет с 5+ концовками
- Пошаговая боевая система с разными врагами
- Возможность собирать команду друзей
- ASCII-графика локаций
- Система морального выбора (очки репутации)
